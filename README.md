
# CodeAlpha FAQ Chatbot

## Project Overview
This project is a simple FAQ chatbot developed using Python and Natural Language Processing (NLP) techniques.

It uses TF-IDF and cosine similarity to match user questions with predefined FAQ questions and return suitable answers.

## Features
- Answers frequently asked questions about AI, Machine Learning, Python, Deep Learning, Data Science, and NLP.
- Uses TF-IDF text vectorization.
- Uses cosine similarity to find matching questions.
- Handles empty input.
- Displays a message for unsupported topics.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

## Installation
Install the required library using:

```bash
python -m pip install -r requirements.txt
```

## How to Run
Run the following command in the terminal:

```bash
python chatbot.py
```

## Sample Questions
- What is AI?
- What is Python?
- What is NLP?
- What is machine learning?
- What is deep learning?

- chatbot.py - Main chatbot program
- requirements.txt - Required Python library
- README.md - Project documentation

## Limitations
The chatbot uses predefined questions and answers. It may not understand every question or provide answers outside its supported topics.

## Conclusion
This project demonstrates a basic FAQ chatbot using Python and NLP techniques.
